# Security policy

If you find a way past one of these guardrails, or a bug that makes one fail open, please report it privately through GitHub's **Report a vulnerability** button (Security tab) rather than in a public issue. I'll acknowledge within a week.

Known, documented bypasses are listed in [docs/limitations.md](docs/limitations.md) and don't need a report, though ideas for closing them are welcome as issues.

Never include real credentials or personal data in a report. Synthetic examples are enough.
